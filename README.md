# AI Security Playbook

**AI Security Playbook: NIST AI RMF, MITRE ATLAS, OWASP ML/LLM Top 10, and 20 incident response playbooks**

## Description

Artificial intelligence systems are increasingly deployed across critical sectors, yet they introduce a class of security risks that traditional frameworks do not fully address. This playbook consolidates three leading frameworks into a single, structured reference for security practitioners and AI engineers:
- **NIST AI Risk Management Framework (AI RMF)**
- **MITRE ATLAS (Adversarial Threat Landscape for AI Systems)**
- **OWASP Machine Learning Security Top 10**
- **OWASP Top 10 for LLM Applications (2023 edition with 2025 mapping)**

The document serves two purposes:
1. **A Learning Resource**: Introduces AI foundations, the NIST AI RMF core functions, the fourteen MITRE ATLAS adversarial tactics, and the critical security risks for ML and LLM systems.
2. **An Operational Reference**: Provides 20 specific incident response playbooks (one per OWASP risk) with concrete detection signals, containment steps, eradication procedures, and recovery actions.
